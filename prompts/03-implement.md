# 03 — Implement (one bounded slice)

```
Implement step <N> of the plan. Nothing else.
- One bounded change, then stop and report. Do not continue to the next step.
- Use the project's own commands (package.json / Makefile / CI), never guess.
- Preview every write: `--pretend`, `-p`, `--dry-run`, or a diff. Show before applying.
- Never run: rm, mv, chmod, docker compose down -v, docker volume prune, *_delete, scan triggers.
- Tags/paths/metadata/notes: stage to <scratch>, not the library or vault.
- Same edit rejected twice → stop, explain the blocker.

Report: CHANGED (file -> what) | COMMANDS (cmd -> exit -> observed) | PREVIEW |
NOT VERIFIED | NEXT (single action).
```
